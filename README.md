# Генератор задач линейного программирования

Курсовой проект по исследованию операций: скрипт генерирует варианты задач линейного программирования, пытается решить их собственным двухфазным симплекс-методом и формирует LaTeX-отчёт с ответами и шагами решения. При установленном `pdflatex` можно получить PDF.

**Что показывает проект:** реализацию численного алгоритма, работу с ограничениями `<=`, `>=`, `=`, генерацию вариантов и автоматическое оформление математических решений.

## Пример результата

- [Сгенерированный PDF](samples/tasks_solutions.pdf)
- [Исходный LaTeX-отчёт](samples/tasks_solutions.tex)

## Быстрый старт

Нужен Python 3 с `pip`. Выполняйте команды **из корневой папки репозитория**:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/main.py
```

В Windows для активации виртуального окружения можно использовать `.venv\Scripts\activate`.

**Важно:** точка входа находится в `src/main.py`, а не в корне. По умолчанию вызов `main_demo(num_tasks=5)` пытается сгенерировать пять задач и сохранить в текущую папку `tasks_solutions.tex`.

Для PDF потребуется дополнительно установить LaTeX-дистрибутив с `pdflatex` и поддержкой русских шрифтов (`T2A`, `babel`). Если `pdflatex` отсутствует, исходный `.tex` всё равно создаётся, а программа сообщает об отсутствии компилятора.

## Как устроено решение

1. Случайно выбираются коэффициенты целевой функции и ограничений.
2. Ограничения приводятся к форме для табличного алгоритма; при необходимости добавляются искусственные переменные.
3. Двухфазная симплекс-процедура ищет допустимое решение и оптимум.
4. Результат дополнительно проверяется на выполнение исходных ограничений.
5. Задачи, ответы и шаги алгоритма записываются в LaTeX и при наличии `pdflatex` компилируются в PDF.

## Ограничения и воспроизводимость

- Генерация использует случайные коэффициенты; seed в текущей точке входа не фиксируется. Поэтому новые запуски могут давать разные варианты.
- Скрипт демонстрирует реализацию алгоритма, но репозиторий пока не содержит автоматических тестов, сравнивающих результаты со сторонним LP-солвером. Это полезное следующее улучшение.
- PDF зависит от внешней установки LaTeX; `numpy` и `scipy` из `requirements.txt` не устанавливают `pdflatex`.
